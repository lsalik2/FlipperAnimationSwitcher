# CHANGELOG.md

## v2.0.0 — Planned

- Increase maximum animation count beyond 128 (heap-allocated animations array)

## v1.5.0 — Planned

- Animation previewer screen

## v1.4.0

- New "Edit Playlist" menu option loads a saved playlist for editing, then saves it back in place or under a new name
- New "Random N" bulk action selects a random set of animations
- Bulk actions (select all / none / invert) now apply only to the animations currently shown by the name filter

## v1.3.0 — Planned

- Bulk select / deselect / invert in the animation list
- Search / filter animations by name in the Create flow
- Configurable default values for new animation selections

## v1.2.0 — Planned

- Restore the previous manifest from manifest.txt.bak via a menu entry
- Mark the currently-applied playlist in the Choose list
- Show playlist stats (count, butthurt/level coverage) in the preview

## v1.1.0

- Back up the previous manifest.txt to manifest.txt.bak before applying a playlist
- New "Backup Playlist" menu option saves the current manifest.txt as a named playlist

## v1.0.0

Initial release:

- Create animation playlists from /ext/dolphin animations
- Apply playlists to manifest.txt with reboot prompt
- Delete saved playlists
- Preview playlist contents via long-press
- Per-animation settings for butthurt, level, and weight in playlist creation
- Custom scrollable list view with checkbox support
- About section linking to the source code
